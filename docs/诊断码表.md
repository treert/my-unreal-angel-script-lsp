## 1. 码号规则

```
AS <大类1位> <序号3位>        例：AS0102
```

| 大类 | 区段 | 含义 |
|---|---|---|
| 0 | `AS0001-0099` | 语法 / 解析：parser 直接拒绝的形态 |
| 1 | `AS0100-0199` | 类型系统：值/引用二分、句柄、转换、布局 |
| 2 | `AS0200-0299` | UE 反射：`UCLASS/USTRUCT/UFUNCTION/UPROPERTY` specifier 约束 |
| 3 | `AS0300-0399` | GC / 属性生成 |
| 4 | `AS0400-0499` | 符号解析：未定义名、重载、命名冲突 |
| 9 | `AS0900-0999` | 本 LSP 独有（引擎无对应行为） |

**为什么诊断要带 code**（三条都与实现进度无关，故现在就定）：

1. **用户抑制**：`// as-ignore: AS0102` 式行内抑制需要稳定标识；
2. **与 Hazelight 扩展共存**：同时启用会双报（[架构设计 §8](架构设计.md#8-风险与未决问题) 风险 4），
   带 code 才能按条抑制而非整体关闭；
3. **文档索引**：`as-docs` 用 `→ AS0201` 引用具体约束，避免重复描述触发条件。

**纪律（仅两条）**：

- **码号只追加，不复用废弃号**；废弃时保留并标 `~~AS0xxx~~ (retired)`。
  `AS0000` 保留不用（避免与「无 code」混淆）。
- **先占号，再写代码**：本文是唯一分配处，实现里禁止出现未登记的 code 字符串。
  Rust 端用单一 `enum DiagCode` 承载，`Display` 输出 `AS0102` 形式。

## 2. 已取证的引擎约束（素材，非实现承诺）

以下形态**引擎确实会报错**，且已定位到源码。**文法刻意放行**它们
（[`../grammar/README.md`](../grammar/README.md)「语法接受 ≠ 语义合法」：中途编辑时整棵树不会崩），
因此若要报错就得靠语义层。P5 按需选用，**未必全部实现**。

「引擎原文」列是取证结果，仅供参考对照——**不是措辞承诺**，本 LSP 可自行拟定更清晰的表述。

| Code | 触发条件 | 引擎原文（参考） | 引擎位置 |
|---|---|---|---|
| `AS0001` | `struct` 内出现 `default` 语句 | `Expected method or property` | `as_parser.cpp:3835` |

### 3.1 已实现形态（M6，D36）

| Code | 状态 | severity | range 落点 | 实现要点 |
|---|---|---|---|---|
| `AS0902` | ✅ M6 | Warning | 打开文档 (0,0) 零宽 | 触发条件合并为「索引内 `.d.as` 数为 0」（dirs 全空与目录无文件两形态统一）；仅对 Script 文档发布；每次重建后重判 |
| `AS0903` | ✅ M6 | Error | `ERROR`/`MISSING` 节点区间 | **语义泛化**（D36）：一切 tree-sitter 解析错误即报——逐节点一条、不深入 ERROR 子树重复计数（`as_syntax::verify_tree` 既有契约）；f-string 嵌套格式说明符是最典型案例（即本表登记时的举例） |

**抑制注释**（官方扩展无既有惯例——已查 `ls_diagnostics.ts`，其无行内抑制机制；
本 LSP 自定。诊断 `source` 一律 `my-as-lsp`）：

```angelscript
// as-ignore: AS0903            ← 同行：抑制该行起始的指定码诊断
// as-ignore: AS0902, AS0903    ← 逗号分隔多码
// as-ignore-next-line: AS0903  ← 上一行：抑制下一行
// as-ignore                    ← 无码：抑制该行全部诊断
```

- 命中口径：诊断 range **起始行**落在生效行；AS0902 落 (0,0) ⇒ 文件首行可抑制；
- 未知码（`DiagCode` 未收录，含已登记未实现的）静默忽略——与 D15「未登记 tag
  静默忽略」同族；块注释不识别；字符串字面量里的标记会误认（已知失真，
  接受——失真面分析见 as-core `diag.rs` 模块头）。

> **`floatIsFloat64` 不设诊断**：配置项配错属静默错误（类型宽度偏差），无法自动检出
> （[架构设计 §8](架构设计.md#8-风险与未决问题) 风险 11）。缓解靠默认值对齐引擎 +
> 状态栏常显生效值。
